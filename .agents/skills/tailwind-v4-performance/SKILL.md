# Tailwind CSS v4 & High-Speed Styling

## Overview
Harnesses the lightning-fast CSS-first engine of Tailwind v4, utilizing CSS `@theme` directives and zero-build overhead.

## Core Rules
- Avoid arbitrary values (`w-[347px]`); adhere strictly to design system spacing tokens.
- Never write nested or duplicate utility classes that fight the CSS cascade.
