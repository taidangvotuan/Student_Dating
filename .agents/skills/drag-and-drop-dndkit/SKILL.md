# Accessible Drag-and-Drop with @dnd-kit

## Overview
Implements accessible, performant drag-and-drop sorting and kanban boards with full keyboard support and screen reader announcements.

## Key Primitives
- `DndContext`: Handles sensors (Mouse, Touch, Keyboard) and collision detection (`closestCenter`).
- `SortableContext`: Manages item sorting order and animations.
