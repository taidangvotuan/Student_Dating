# SOC 2 & HIPAA Engineering Compliance

## Overview
Translates regulatory compliance mandates into automated engineering controls, immutable audit trails, and cryptographic guarantees.

## Non-Negotiable Engineering Controls
- Encrypt all databases, snapshots, and object stores using customer-managed keys (KMS).
- Route all administrative actions to tamper-proof, append-only audit log streams.
