# Penetration Testing & Red-Teaming Playbook

## Overview
Simulates real-world adversary attacks against applications and APIs to identify unpatched attack surfaces before malicious actors do.

## Testing Phases
1. **Reconnaissance**: Subdomain enumeration, port scanning (Nmap), and tech stack fingerprinting.
2. **Vulnerability Assessment**: Automated scanning (ZAP, Burp Suite) paired with manual boundary probing.
3. **Exploitation & Verification**: Safely prove exploitability with Proof of Concept (PoC) without data destruction.
4. **Remediation Reporting**: Provide CVSS 3.1 severity scores and verified developer remediation snippets.
