# Progressive Web Apps & Service Worker Caching

## Overview
Transforms web applications into installable, offline-capable mobile and desktop apps.

## Workbox Caching Strategies
- **Cache-First**: Static versioned assets (images, fonts, bundles).
- **Stale-While-Revalidate**: Fast UI renders with background cache updating for news/feeds.
- **Network-First**: Transactional data and user balance inquiries.
