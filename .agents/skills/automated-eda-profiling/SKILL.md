# Automated Exploratory Data Analysis (EDA)

## Overview
Generates comprehensive visual distribution profiles, missing value heatmaps, and correlation matrices in seconds on new datasets.

## Audit Checklist
- Check for skewed distributions requiring log transforms.
- Identify collinear feature pairs (correlation coefficient > 0.85).
- Audit missingness patterns (MCAR, MAR, MNAR).
